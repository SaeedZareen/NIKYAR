# نیک‌یار — سیستم طراحی (MASTER)

> منبع حقیقت برای همه‌ی صفحه‌ها. الگوی مرجع: **نرم‌افزارهای اداری ایرانی از نوع راهکاران سیستم**
> (فشرده، آشنا برای کاربر اداری، کارآمد روی لپ‌تاپ ۱۳۶۶×۷۶۸ با بزرگ‌نمایی ۱۲۵٪). قواعد دسترس‌پذیری از مهارت
> **ui-ux-pro-max** (`.claude/skills/ui-ux-pro-max`) و قوانین **وایب‌فارسی** (`AGENTS.md`).

## ۱. جهت طراحی

| مورد | تصمیم |
|---|---|
| نوع محصول | سامانه‌ی اداری (BPMS / ERP) برای کاربری روزانه و طولانی |
| سبک | **فشرده و اداری به سبک راهکاران**: نوار بالای سرمه‌ای، منوی درختی تاشو در راست، زبانه‌ی صفحه‌های باز، نوار ابزار فشرده، جدول متراکم با خطوط ستون، فرم با برچسب کنار فیلد |
| اندازه‌ی مرجع | ۱۰۹۳×۶۰۰ (لپ‌تاپ اداری ۱۳۶۶×۷۶۸ با ۱۲۵٪)؛ سپس ۱۹۲۰ و ۳۷۵ |
| حالت | روشن پیش‌فرض؛ تیره به‌صورت جفت؛ «مطابق سیستم» |
| ضدالگوها | فاصله‌ی زیاد و کارت‌های بزرگ، متن درشت، چیدمان «لندینگ‌پیج»، فرم‌ساز سه‌ستونی باریک، حاشیه‌ی خالی در صفحه‌های عریض |
| ضروری | حلقه‌ی فوکوس ۳px، لینک «پرش به محتوا»، ناوبری کامل با صفحه‌کلید، کنتراست AA، هدف لمسی ≥۲۴px (و ۴۴px روی لمسی) |

## ۳. تایپوگرافی

فونت Vazirmatn، `letter-spacing: 0`، اندازه‌ی پایه **۱۴px** (`html { font-size: 87.5% }`)، اعداد جدول هم‌عرض.

| نقش | کلاس | اندازه |
|---|---|---|
| عنوان صفحه (`h1`، یکی) | `text-lg font-bold` | ~۱۶ |
| عنوان پنل (`h2`) | `text-sm font-bold` | ~۱۳ |
| متن، کنترل، جدول | `text-sm` / `text-base` | ۱۳ / ۱۴ |
| فراداده | `text-xs` | ~۱۲ — فقط فراداده |

## ۴. فاصله، شکل، حرکت

- فاصله‌ها روی شبکه‌ی ۴px و فشرده: بین پنل‌ها `gap-3`/`mb-3`، داخل پنل `p-3 lg:p-4`.
- ارتفاع: نوار بالا ۴۸px، زبانه‌ها ۳۶px، دکمه‌های نوار ابزار و فیلترها `h-8`، سرستون جدول `h-9`، ردیف `py-1.5`.
- شعاع کم: کنترل ۴px، سطح ۶px. کارت داخل کارت ممنوع.
- حرکت: ۱۲۰ms، فقط `transform`/`opacity`، احترام به `prefers-reduced-motion`.

## ۵. الگوهای صفحه

| الگو | قاعده |
|---|---|
| پوسته | `Shell`: نوار بالای سرمه‌ای (لوگو، جست‌وجوی `Ctrl+K`، تاریخ، تم، اعلان، کاربر) + منوی درختی تاشو (گروه‌ها باز/بسته، حالت فقط‌آیکون) + `PageTabsProvider` (زبانه‌ی صفحه‌های باز، حداکثر ۱۰) |
| ساختار صفحه | `PageHeader` فشرده (مسیر کوچک، `h1`، نوار ابزار) ← `Panel`ها؛ عرض کامل، بدون حاشیه‌ی خالی |
| فضای کار | فرم‌ساز و فرایندساز تمام‌ارتفاع‌اند: منو خودکار جمع می‌شود، نوار ابزار ۴۸px، جعبه‌ابزار / بوم / تنظیمات |
| فهرست‌ها | `ResponsiveList`: جدول متراکم با خطوط ستون، سرستون چسبان، ردیف تک‌خطی (`nowrap`)، ردیف = لینک واقعی؛ کارت روی موبایل |
| فیلترها | `ListToolbar` + `ToolbarFilter` (برچسب کنار کنترل)؛ در نشانی صفحه (`useUrlState`) |
| فرم‌ها | `FieldRow`: برچسب کنار فیلد روی دسکتاپ (بالای فیلد روی موبایل)؛ خلاصه‌ی خطا پس از ارسال ناموفق |
| فقط‌خواندنی | `KeyValue` / فهرست تعریف با خط‌چین، نه فیلد غیرفعال |
| فرم‌ساز | WYSIWYG: فیلد روی بوم همان‌طور دیده می‌شود که کاربر می‌بیند؛ افزودن با کلیک یا کشیدن؛ ذخیره‌ی خودکار؛ واگرد/ازنو؛ تنظیمات در زبانه‌های عمومی/قواعد/شرط نمایش/پیشرفته |
| پنجره‌ها | Esc برای بستن؛ اگر تغییر ذخیره‌نشده دارد تأیید بگیرد |
| بارگذاری / خالی / خطا | اسکلت هم‌شکل؛ پیام مشخص + اقدام بعدی؛ دکمه‌ی «تلاش دوباره» |
