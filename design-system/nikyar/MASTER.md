## ۴. فاصله، شکل، عمق، حرکت

- فاصله‌ها روی شبکه‌ی ۴px: `gap-2/3/4/6/8`؛ بین بخش‌های صفحه `space-y-6` یا `gap-6`.
- شعاع: کنترل و فیلد ۶px، سطح و پنجره ۱۲px.
- عمق: سطح‌ها فقط یک مرز مویی + سایه‌ی بسیار کم؛ **کارت داخل کارت ممنوع** (`elevation-consistent`).
- حرکت: ۱۶۰ms، فقط `transform`/`opacity`، احترام به `prefers-reduced-motion`.
- هدف لمسی: ≥۴۴px روی صفحه‌های لمسی (`@media (pointer: coarse)`)، فاصله‌ی ≥۸px.

## ۵. الگوهای صفحه

| الگو | قاعده |
|---|---|
| ساختار صفحه | `PageHeader` (یک `h1`، مسیر برای عمق ≥۲، **یک** اقدام اصلی) ← محتوا |
| فهرست‌ها | `ResponsiveList`: جدول روی دسکتاپ، کارت روی موبایل؛ هر ردیف یک **لینک واقعی** (صفحه‌کلید، باز شدن در زبانه‌ی جدید)؛ ستون‌های قابل مرتب‌سازی با `aria-sort` |
| فیلترها | در نشانی صفحه ذخیره می‌شوند (`useUrlState`) تا «بازگشت» و اشتراک لینک حالت را حفظ کند |
| فرم‌ها | برچسب بالای فیلد، خطا زیر فیلد، پس از ارسال ناموفق **خلاصه‌ی خطا** بالای فرم و فوکوس روی آن |
| حالت فقط‌خواندنی | **فهرست تعریف** (برچسب/مقدار)، نه فیلد خاکستری شبیه غیرفعال (`read-only-distinction`) |
| دکمه‌ی ارسال | هنگام انتظار غیرفعال + نشانگر بارگذاری (`loading-buttons`) |
| پنجره‌ها | بستن با Esc؛ اگر تغییر ذخیره‌نشده دارد، پیش از بستن تأیید بگیرد (`sheet-dismiss-confirm`) |
| حذف | همیشه با پنجره‌ی تأیید و رنگ `destructive`، جدا از اقدام اصلی |
| زبانه‌ها | زبانه‌ی فعال در نشانی صفحه (`?tab=`) برای لینک مستقیم |
| بارگذاری | اسکلت هم‌شکل محتوای نهایی؛ خطا با پیام و دکمه‌ی «تلاش دوباره» |
| خالی | پیام مشخص + اقدام بعدی |
| ناوبری | نوار کناری ثابت روی دسکتاپ، کشو روی موبایل؛ جست‌وجوی سراسری با `Ctrl+K`؛ لینک «پرش به محتوا»؛ فوکوس و عنوان سند پس از تغییر صفحه |
