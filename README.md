# نیک‌یار

**سامانه‌ی یکپارچه‌ی مدیریت فرایند و منابع سازمانی، ماژولار و قابل توسعه به ERP**

### هسته‌ی مرکزی
- **فرایندساز BPMN** با پنل فارسی: انتساب بر اساس چارت سازمانی، دسترسی فیلدها در هر مرحله، دکمه‌های اقدام (تأیید/رد/بازگشت)، مهلت انجام، اقدام سیستمی
- **فرم‌ساز بدون کدنویسی**: ۲۵ نوع فیلد (کد ملی، شبا، کارت، موبایل، کد پستی، استان و شهر، تاریخ شمسی، مبلغ تومان، جدول چندردیفی، پیوست، …)، نمایش شرطی، پیش‌نمایش و نسخه‌بندی
- **مدیریت فهرست‌های پایه**: فهرست‌های سیستمی (قفل) و قابل‌ویرایش
- **کارتابل اداری**: ارجاع، یادداشت، مهلت و دیرکرد، اعلان، پیگیری با نقشه‌ی فرایند
- **کاربران، ساختار سازمانی، نقش‌ها و مجوزها** + **سوابق تغییرات** برای همه‌ی رکوردها
- **سیستم ماژول و لایسنس** برای فروش ماژول‌به‌ماژول

### ماژول پرونده‌ی پرسنلی
اطلاعات هویتی، تماس، استخدامی، تحصیلات، سوابق کاری، افراد تحت تکفل، حساب‌های بانکی، مدارک،
**فیلدهای سفارشی سازمان (low-code)**، گزارش نیروی انسانی و خروجی اکسل.

### طراحی و تجربه‌ی کاربری
سیستم طراحی «اداری» بر اساس مهارت **UI/UX Pro Max** (`.claude/skills/ui-ux-pro-max`) و قوانین
**وایب‌فارسی**؛ منبع حقیقت: [`design-system/nikyar/MASTER.md`](design-system/nikyar/MASTER.md).
تم روشن (پیش‌فرض)، تیره و «مطابق سیستم»؛ کنتراست AA در هر دو تم؛ بدون خطای دسترس‌پذیری در آزمون axe-core.

### فناوری
Django + DRF + SpiffWorkflow + PostgreSQL · React + TypeScript + Tailwind v4 + کامپوننت‌های **وایب‌فارسی**

## نصب روی ویندوز (ساده‌ترین روش)

1. **Git**، **Python 3.12+** و **Node.js LTS** را نصب کنید.
   هنگام نصب Python، تیک گزینه‌ی «Add python.exe to PATH» را بزنید.
2. ریپو را دانلود کنید (مثلاً در `C:\xampp\htdocs\NIKYAR`).
3. روی فایل `install-windows.bat` دابل‌کلیک کنید (فقط یک بار).
4. برای اجرا، روی `start-windows.bat` دابل‌کلیک کنید. مرورگر خودکار روی `http://localhost:8000` باز می‌شود.

## اجرای سریع برای توسعه

پیش‌نیاز: Python 3.12 یا بالاتر، Node.js 20 یا بالاتر

**ترمینال ۱ (بک‌اند):**
```bash
cd backend
python3 -m venv ../.venv && source ../.venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

**ترمینال ۲ (فرانت‌اند):**
```bash
cd frontend
npm install
npm run dev
```

سپس آدرس `http://localhost:5173` را باز کنید.

| کاربر نمایشی | نقش | رمز |
|---|---|---|
| `admin` | مدیر کل (همه‌ی بخش‌ها) | `nikyar123` |
| `hr_manager` | مسئول امور پرسنلی (پرونده‌ها، فهرست‌های پایه) | `nikyar123` |
| `it_manager` | مدیر (مدیرِ developer؛ تأیید مرخصی) | `nikyar123` |
| `developer` | کارمند | `nikyar123` |
| `hr_expert` | کارشناس امور اداری (ثبت نهایی مرخصی) | `nikyar123` |

**سناریوی نمایشی:** با `developer` یک «درخواست مرخصی» ثبت کنید، با `it_manager` موافقت کنید و
با `hr_expert` آن را ثبت نهایی کنید. سپس در «پیگیری درخواست‌ها» نقشه‌ی فرایند و سوابق پرونده را ببینید.

## نصب روی سرور سازمان (Production)

```bash
cp .env.example .env
```
رمزها را در فایل `.env` تغییر دهید. سپس:
```bash
docker compose up -d --build
```
```bash
docker compose exec app python manage.py createsuperuser
```
سامانه روی پورت `8080` در دسترس است.

**لایسنس:** فایل `license/license.json` را بر اساس `license/license.example.json` بسازید.
بدون این فایل، سامانه در حالت «نسخه‌ی آزمایشی» با همه‌ی ماژول‌ها اجرا می‌شود.

## اجرای آزمون‌ها
```bash
cd backend && python manage.py test tests
```
