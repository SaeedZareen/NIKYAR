# نقشه‌ی راه

| ۱ | سیستم طراحی و کیت رابط کاربری: پوسته (منو، زبانه‌های صفحه، جست‌وجوی سراسری)، جدول داده‌ی کامل، فیلدهای فرم ایرانی، تاریخ شمسی (آوان)، الگوهای صفحه | انجام شد |
