# نقشه‌ی راه

## ✅ مرحله‌ی ۱: هسته و گردش کار (انجام‌شده)
- ورود کاربران، چارت سازمانی، سمت‌ها، نقش‌ها
- طراح فرایند BPMN فارسی با فرم‌ساز و شرط‌ساز
- کارتابل، ارجاع، یادداشت، لغو، سوابق پرونده
- نمایش وضعیت پرونده روی نقشه‌ی فرایند
- نسخه‌بندی فرایند، سیستم ماژول و لایسنس، نصب با Docker

## مرحله‌ی ۲: تکمیل BPMS
- [ ] پیوست فایل در فرم‌ها و پرونده
- [ ] مهلت انجام کار و یادآوری (رویداد زمان‌سنج)
- [ ] اعلان پیامکی (درگاه‌های ایرانی) و ایمیلی
- [ ] جانشین/تفویض اختیار در زمان مرخصی
- [ ] گزارش‌ها: زمان انجام هر مرحله، گلوگاه‌ها، کارهای معوق
- [ ] چاپ فرم رسمی پرونده (PDF با سربرگ سازمان)
- [ ] امضای لایسنس با RSA (جلوگیری از دست‌کاری)
- [ ] ورود یکپارچه با Active Directory / LDAP

## مرحله‌ی ۳: زیرساخت ERP
- [ ] «تسک سرویس»: اتصال گام‌های فرایند به ماژول‌ها (مثلاً ثبت خودکار سند)
- [ ] سامانه‌ی اسناد و شماره‌گذاری رسمی
- [ ] تنظیمات سال مالی، اشخاص، مراکز هزینه

## مرحله‌ی ۴: ماژول‌های ERP (هر کدام قابل فروش جداگانه)
- [ ] انبار و کالا
- [ ] خرید و تدارکات
- [ ] حسابداری و خزانه
- [ ] منابع انسانی و حقوق و دستمزد
- [ ] فروش و مشتریان
